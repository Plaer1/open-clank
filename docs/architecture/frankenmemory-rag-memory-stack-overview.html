SYS 001 One bank, many ways in

FrankenMemory is Open Clank’s local-first semantic memory plane. It receives ordinary conversation, authored knowledge, documents, repositories, reviews, and work traces; turns them into versioned evidence and knowledge; publishes disposable search and graph projections; and returns bounded, cited, scope-safe context to people and agents.

The system is intentionally asymmetric. The host can admit sources, build and publish generations, apply reviewed changes, export, roll back, and forget. Models get bounded read operations and proposal paths. They do not receive raw administrative tools, filesystem roots, policy authority, or the ability to assign Trust.

The governing invariant Canonical meaning lives in one Rust/SQLite authority. Everything optimized for retrieval—FTS, vectors, graphs, chunks, summaries, findings, caches—is a versioned projection with lineage and a rebuild path.

Remember

Facts, preferences, episodes, decisions, actions, outcomes, corrections, open questions, and authored material become scoped, revisioned knowledge with evidence.

Understand

Typed document IR, code structure, entities, relations, tests, routes, calls, claims, findings, and work traces preserve where an assertion came from.

Retrieve

Exact, FTS, vector, structural, entity, and relation lanes fuse deterministically after owner and scope filters have already run.

Forget

One canonical erasure intent fans out through a fenced outbox, clears projections and caches, survives restore, and leaves a content-free receipt.

Conversation & manual

Brain writes and directed manage_memory actions enter immediately with owner intent. Completed Chat/Agent/MiMo turns pass through one transport-blind post-response seam. Incognito, temporary, compare, and policy-excluded turns do not enter memory.

Transcript & work

Versioned adapters normalize user, assistant, developer/system, tool call/result, file read/write/edit, command, verification, error, decision, outcome, feedback, and correction records while preserving event time separately from ingest time.

Authored knowledge

Supported MEMORY-style sources and memory exports ingest idempotently by source revision and content hash. The authored file remains evidence; checkpoints and unrelated task artifacts do not silently become semantic memory.

Rich documents

Text, Markdown, DOCX, PDF, tables, code blocks, pictures/captions, equations and attachments enter one parser registry and typed document IR before chunk, graph or vector work begins.

Repositories

Authorized opaque repository resources produce sealed VCS/working-tree snapshots, a complete coverage ledger, language-plugin results and private code generations that converge between full and incremental builds.

Review & traces

Diffs, SARIF, findings and agent work traces are sealed against exact code, rule, model, prompt, tool and budget identities. They enter as evidence—never as truth or executable policy.

MEM 418 Regular memory and Trust

Versioned knowledge

A stable block identifies subject + predicate + claim slot + scope. Its value is typed; its history is append-only. Edit, correct, resolve, reopen, retract, supersede, revert, diff and blame operate against explicit revisions. A stale writer records or returns a conflict instead of overwriting the accepted head.

Memory semantics

Action, decision, rationale, alternative, outcome, verification, feedback and correction evidence preserve when the event happened and when it was observed. Late imports do not outrank later corrections merely because they arrived last.

Activation & origins

Local, imported, personal-working, session-working and shared/group material carry explicit origin and activation policy. Withheld evidence remains out of active recall until the owner or policy admits it. Aggregate diagnostics show withheld and capped counts without leaking bodies.

Reversible working memory

Conversation and work summaries are derived artifacts with source event IDs, hashes, covered range, omissions, prompt/schema/model/config and job lineage. Failure preserves original context. A summary never becomes the only copy, never outranks its sources, and never assigns Trust.

Trust asks one question “How much do I trust this information?” The wire state is either unreviewed with no value or assigned with a finite owner-assigned value from 0 to 1. It is revisioned, attributable, explainable and scope-bound.

Trust

Owner-relative epistemic judgment. Only an authorized owner action assigns or revises it.

Prompt authority

Whether recalled material has behavioral force. It consumes endorsement and policy, not a scalar alone.

Activation

Whether content participates in active memory. Origin, review and policy control it.

Relevance

Query-local retrieval rank. It changes per query and is never stored as Trust.

Evidence strength

Quality of a parser, resolver or witness path. It can be corrected or down-rated.

Technical score

Precisely named OCR, extraction, consistency, model or rerank measure.

Executable trust

Open Clank Hexes, TLS, tools and grants. This security authority is never derived from memory.

Prompt-stable recall

Stable owner-approved persona, scenario and tool guidance lives in a stable system tail. Dynamic atomic memory lives in a guarded data section. Large source, code and document bodies arrive only on demand.

Safe evolution

Corroboration and contradiction append typed evidence and may produce a Trust proposal. Dedup creates a reversible merge/supersession proposal. Neither silently rewrites Trust or deletes a “lower-scored” record.

Dedicated Memory model

The Settings Memory purpose independently routes extraction, graph enrichment, import interpretation, tidy/audit, conflict help, consolidation and working-summary generation. Utility and Embeddings remain separate; no hidden fallback crosses the boundary.

RAG 705 Rich-document and Graph RAG

The RAG path is a canonical document lifecycle, not a loose vector collection. Source revision, parser, IR, chunker, locator, graph extraction, embedding, cache and retrieval generation all have independent identity.

Typed document IR

Stable document, block, segment and asset IDs preserve source/content hashes, page and dimensions, character/byte/line spans, optional bounding boxes, heading trees, ordered children, language, and typed segment kinds.

Lazy versioned parsers declare suffix, MIME, magic, capabilities, dependencies, size limits, security class and IR version. Plain text, Markdown, pypdf, MarkItDown and attachment routes converge here. Parser output is untrusted structured data.

Entity/relation projection

Each entity and relationship points back to exact source chunks and supporting spans plus extractor, prompt, schema, route/model and evidence strength. Alias merging preserves ambiguity. Derived rows are independently unreviewed; they reference rather than inherit source Trust.

Stable citations

Every returned unit resolves through an owner/source-revision-scoped typed locator. The facade rechecks access and returns a bounded source view. Raw paths and object keys are not authority and are not exposed as agent capabilities.

No Chroma dependency

Exact and FTS retrieval work directly from the canonical SQLite bank. Embeddings are optional, fingerprinted immutable generations. Missing vectors or a failed model degrade visibly to valid lexical and graph lanes; they never create a second RAG authority.

CODE 512 Code memory, review and Hex

Move-stable identity

An opaque owner-bound repository ID joins a full 40-character VCS snapshot descriptor, ref, dirty/staged/unstaged/untracked inputs and content hashes. Absolute checkout roots stay in the authorized host registry, not durable node IDs.

Coverage-complete index

Every discovered file closes as indexed, unchanged, deleted, renamed, binary, oversize, unsupported, ignored, outside-root, permission-denied, parse-failed, budget-truncated or cancelled. Full and incremental builds converge before publication.

Language plugins

Rust, Python, TypeScript and JavaScript plugins expose definitions, signatures, parents, spans, imports/exports, calls/references, tests and resolver evidence. Missing capability is reported as coverage, never fabricated completeness.

Code retrieval

Exact/FTS, structural, optional vector and weaker historical lanes return symbol context, references, callers/callees, call hierarchy, impact paths, related tests, service flows, claims, findings and bounded source windows with witnesses and coverage.

Sealed review evidence

Diff selection, rules, model/prompt/schema, tool/runtime, budget and policy are sealed. Findings relocate through deterministic hunk → file → unique cross-file matching, retain SARIF fingerprints and progress through explicit evidence states.

Advisory below authority

Review rules compile to a deterministic file→effective-rule projection. Findings can nominate a memory correction, decision, task, skill revision or spell candidate. They cannot alter .hex, the Hexes authority, Trust, activation, grants, routes, plans or tools.

Q 007 Curiosity and open questions

Curiosity is stored as a durable known unknown. A question can travel through recall, research, code and document retrieval, evidence collection, answer proposal, owner policy, same-block resolution, revision history and later correction without becoming a second task or notes system.

Human-minted

Brain or a directed memory action creates the open question. Automatic extraction cannot mint a user agenda. The subject, predicate, claim slot, scope, source and expected answer type become explicit.

Surfaced naturally

The bounded memory digest carries up to five scoped questions. They live in owner-agenda guidance with “weave in when relevant; never interrogate” framing and remain searchable as [open question].

Scope-aware

Workspace and global questions follow the normal effective-scope set. Equivalent questions open in three distinct workspaces promote idempotently to one global known unknown; originals retain merge lineage.

Evidence gathered

Conversation, research, code, documents, review and work results can support an answer candidate. Recalled text remains inert data; source Trust and technical evidence stay separate.

Same-block resolution

An accepted answer appends a typed value to the existing question block under expected-revision CAS, advances status from open to active, links evidence/change set, and emits projection events. No duplicate “answer memory” is required.

Reopen and correct

Reopen restores a typed null value; correct, retract, supersede and revert append later revisions. A stale answer cannot close a question whose head has moved. Full history, actor, reason and blame remain available.

Intent is not epistemic Trust Human provenance proves that the owner wants the question carried. It does not automatically mark the eventual answer as trusted. The answer remains unreviewed until an explicit owner Trust assignment exists, and prompt authority remains a separate policy decision.

OUT 227 The exgest system

Exgest names the whole outbound side: scope-safe candidate retrieval, deterministic fusion, optional reranking, exact context rendering, explanation, read-only delivery, scoped export, and erasure propagation.

Bind before search

Owner, workspace, project, repository snapshot, policy generation, model identity, activation and forget watermarks become part of the query before any lane sees a candidate.

›
Retrieve, fuse, rerank

Exact · FTS · vector · structural · entity · relation candidates retain lane rank, score, witnesses, coverage and generation. Weighted RRF fuses deterministically. An admitted reranker can only reorder already-scoped candidates.

›
Render and deliver

Complete typed units fit an exact tokenizer budget. Each unit has a resolvable citation and explanation. Output travels to Brain, APIs, context, Agent tools, structured references or scoped export.

Candidate contract

Every hit preserves exact scope, source/snapshot revision, projection generation, lane ranks, score components, source Trust reference, evidence strength, degradation, coverage and truncation. Cross-tenant candidates never enter a shared scorer, cache, model input or metrics label.

Rerank contract

The candidate pool is larger than final k. Route/model, input hashes/order, windows, limits and consent are bound. Invalid indices, duplicate results, non-finite scores, timeout or outage preserve fused order and set degraded=true with a reason.

Exact context

Budgets allocate system, query, history, entities, relationships, chunks, headings, citations and render overhead. Truncation happens only at complete typed-unit boundaries; unresolved citations are excluded and explained.

Prompt firewall

Recalled transcript, code, review and document text is untrusted data. System-like tags, tool syntax and markup cannot invoke a tool, widen a grant, mutate immutable prompt sections or become owner guidance without prompt-authority policy.

Read-only agent plane

Agents can recall, search, inspect a memory, retrieve a citation, fetch bounded source, explore symbols/references/calls/tests/impact and request explanations. Host identity and scope are supplied outside model arguments.

Operator exgest

Authenticated host flows provide scoped memory export, SARIF import/export, source and citation views, safe rebuild/rollback and broad export. Index, apply, publish, remove and administrative graph operations remain absent from agent profiles.

Forget is a first-class outbound operation A canonical transaction records erasure intent and an outbox event. Fenced consumers remove dependent evidence, chunks, embeddings, graph cues, findings, traces, summaries, watermarks and caches. Restore replays the content-free erasure ledger before serving, so rebuild and reimport cannot resurrect the forgotten source.
SAFE 600 Privacy, failure and degradation

Privacy before persistence

Redaction and scope enforcement happen before canonical writes, embeddings, indexes, graph properties, caches, sync/export, telemetry and logs. Credentials, tokens, keys, auth headers and detected secrets are never retained.

Filesystem & parser safety

Opaque authorized resources, canonical and post-symlink checks, no-shell reads, TOCTOU detection, archive entry/ratio/nesting limits, page/image/token budgets, cancellation and contained subprocesses guard local ingest.

Network boundary

External URLs are disabled by default. Admitted fetches require scheme/host policy, DNS and rebinding defense, private/loopback/link-local IPv4/IPv6 rejection, redirect revalidation, MIME/magic, deadlines, byte limits and credential stripping.

OPS 440 Operations and proof

The stack is operable as a product, not only as a schema: routes, Brain, Settings, Agent/MiMo, migrations, backup/restore, rollback, diagnostics, accessibility, security and packaged runtimes share one contract.

Memory

Fresh owner → configure Chat/Utility/Memory/Embeddings → remember manual and extracted facts → import rich document → recall with citations → edit/history/blame → consolidate → restart → forget → rebuild → prove no resurrection.

Code

Authorize repository → full snapshot index → symbols/references/calls/tests/impact → difficult edit/rename/delete sequences → incremental/full parity → finding relocation → restart → prove identity, coverage and read-only access.

RAG

Ingest text, Markdown, DOCX, PDF, table and picture/caption fixtures → inject parse/chunk/embed/extract faults → publish → query five lanes → rerank/degrade → exact citations → update/rollback/forget.

Policy

Compile advisory rules → review changed code → dedup/critic/SARIF → propose candidate → prove no policy/Trust/grant mutation → promote through the existing owner path → retain exact lineage.

Quality telemetry

Recall@k, MRR, nDCG, source/citation accuracy, false activation/leakage, code navigation and impact success, lane contribution, coverage, latency and exact token/candidate budgets are measured on deterministic corpora.

Operational telemetry

Startup/readiness, capture/recall/forget, job phase latency, queue depth, retries, scan and parse throughput, cache hit, rerank degradation, pointer health, cancellation and retention are metadata-only by default.

Packaged parity

Current-source Rust, packaged Python, browser discovery, supervisor/engine, migrations and assets carry verifiable identities across admitted macOS, Linux and Windows targets. ACP compatibility and Rust capabilities preserve memory behavior across the supervisor seam.

Operational invariants
  • Database, WAL and SHM are owner-only and re-locked across creation, restart, migration and recovery.
  • Additive owner-scoped migrations provide preflight, dry run, counts, checkpoint/resume, backup and rollback boundaries.
  • Optional vectors, models and network services never gate canonical/lexical readiness.
  • Every acceptance row records exact source/artifact identity, command, environment, owner/scope, duration, result and retained redacted evidence.
  • Brain, Settings, code/RAG views and destructive confirmations meet keyboard, focus, screen-reader, contrast and responsive requirements.
  • No reference clone, copied Chunkr source, second store, hidden provider fallback or unowned compatibility path ships.

Glossary

Canonical
The durable source of semantic truth and lifecycle history.

Projection
A derived, versioned, disposable representation optimized for search, graph traversal, display or evaluation.

Ingest
Authority binding, redaction, source/evidence capture, normalization, review/activation and generation publication.

Exgest
Retrieval, fusion, rerank, exact rendering, explanation, delivery, scoped export and forget propagation.

Trust
An explicit owner-relative epistemic assignment, not relevance, confidence, evidence strength or permission.

Known unknown
A stable typed knowledge block whose current value is null and whose question remains open.

Generation
An immutable derived build validated before a compare-and-swap publication pointer can expose it.

Prompt authority
The separate policy decision that determines whether recalled information can act as behavioral guidance.

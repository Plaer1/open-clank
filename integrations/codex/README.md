# Open Clank Codex Integration

This directory contains the Codex plugin/skill bundle for Open Clank.

Use the setup commands generated by **Settings → Integrations** for the
installation's current address and token. Use `OPEN_CLANK_URL` and `OPEN_CLANK_API_TOKEN` for scoped access. Use verified HTTPS for remote access and keep tokens private.
These integration credentials are separate from app login, model subscription
login and mailbox authorization.

## User Flow

1. Open Open Clank Settings > Integrations.
2. Add a Codex Agent.
3. Copy the full setup commands shown after the generated token.
4. Toggle the tools Codex is allowed to use.
5. Configure the terminal Codex session:

```bash
export OPEN_CLANK_URL=http://127.0.0.1:7777
export OPEN_CLANK_API_TOKEN=ody_generated_token
mkdir -p ~/plugins
curl -fsSL -H "Authorization: Bearer $OPEN_CLANK_API_TOKEN" "$OPEN_CLANK_URL/api/codex/plugin.zip" -o /tmp/openclank-codex-plugin.zip
python3 -m zipfile -e /tmp/openclank-codex-plugin.zip ~/plugins
python3 - <<'PY'
import json
from pathlib import Path

p = Path.home() / ".agents" / "plugins" / "marketplace.json"
p.parent.mkdir(parents=True, exist_ok=True)
if p.exists():
    data = json.loads(p.read_text())
else:
    data = {"name": "personal", "interface": {"displayName": "Personal"}, "plugins": []}

data.setdefault("name", "personal")
data.setdefault("interface", {}).setdefault("displayName", "Personal")
plugins = data.setdefault("plugins", [])
entry = {
    "name": "openclank",
    "source": {"source": "local", "path": "./plugins/openclank"},
    "policy": {"installation": "AVAILABLE", "authentication": "ON_INSTALL"},
    "category": "Productivity",
}
data["plugins"] = [item for item in plugins if item.get("name") != "openclank"] + [entry]
p.write_text(json.dumps(data, indent=2) + "\n")
PY
codex plugin add openclank@personal
```

6. Verify:

```bash
python3 ~/plugins/openclank/scripts/openclank_api.py capabilities
```

Codex must use `/api/codex/*` endpoints. SSH, Docker, direct Python imports, database queries, and MCP internals bypass Open Clank Settings and must not be used for user data access.

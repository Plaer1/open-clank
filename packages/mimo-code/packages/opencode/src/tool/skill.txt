Load a specialized skill when the task at hand matches one of the skills listed in the system prompt.

Use this tool to inject the skill's instructions and resources into current conversation. The output may contain detailed workflow guidance as well as references to scripts, files, etc in the same directory as the skill.

The skill name must match one of the skills listed in your system prompt.

invocation: "explicit" takes effect only when the user themselves requested this skill by name
this turn (a /slash-command or user mention) or the host issued a user-explicit token. A model
claim of "explicit" without that user-originated signal is ignored and stays in "model" mode.
Autonomous model selection leaves invocation unset (defaults to "model"). Disabled, untrusted,
or revoked skills cannot run in either mode. Hidden skills are never listed in available_skills
and are only reachable when the user requested them. Hidden alone never grants trust.

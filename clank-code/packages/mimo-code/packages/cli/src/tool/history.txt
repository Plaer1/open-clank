Search or inspect the authorized conversation history. For ordinary recall, use memory first when it is useful, then search history for the original trajectory.

Operations:
  - search: find matching messages or tool parts.
  - around: inspect messages around a result.
  - get: inspect an ordinary retained part.
  - media: inspect retained attachment locators.
  - exact_output_query: search one eligible exact tool output for a case-sensitive literal, with UTF-8 byte ranges. Supply message_id, part_id, revision, content_hash and query; byte_offset defaults to 0 and limit defaults to 20 (maximum 50). Use next_offset for the next match page. The original selector in the JSON result recovers the complete output via exact_output.
  - exact_output: directly recover an eligible exact tool-output page from its message ID, part ID, revision and content hash. The result is JSON: decode its `text` string for the exact page. Use the returned `nextOffset` as `byte_offset` for the next page; do not guess an offset. A null `nextOffset` means the output is complete. An unavailable result must not be replaced with a different source.

Managed history is constrained by the current authenticated account and permissions.

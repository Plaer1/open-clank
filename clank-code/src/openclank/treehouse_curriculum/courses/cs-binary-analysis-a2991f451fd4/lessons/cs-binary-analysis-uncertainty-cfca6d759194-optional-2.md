# Optional worksheet: a reproducible small experiment

Choose one narrow question about an input you are authorized to inspect. Record a hypothesis and a competing explanation, the owned input and its checksum, the tool and version, and the exact bounded operation. Write down the observation separately from your interpretation: for example, a static disassembly or reference is a provider's static interpretation, not proof that a runtime executed an instruction or edge.

If the tool cannot identify a function, or the result is partial, retain that failed or partial outcome rather than silently replacing it with a stronger claim. What specific next observation would distinguish the explanations? Record the limit of your experiment and the result you actually saw, including an empty or unavailable result.

When appropriate, explicitly retain an approved analysis snapshot with the selected evidence and checksums. Later, an authorized comparison can show per-file and folder changes or report inaccessible and incomplete coverage. The retained snapshot is historical evidence: it does not give live access to the original files, prove an unchanged runtime, or turn a virtual address into a file offset.

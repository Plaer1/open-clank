# Writing the Instruction Manual

Use **`-quiet, but with all required info`**. Start with what the reader wants to do. Name the control they can find, the prerequisite that matters, and what they should see after the action. Explain a recovery step or irreversible consequence where the reader makes that decision. Link to the page that owns a longer procedure.

Lead with the result a reader can get specifically in Open Clank. Skip generic editor lessons and catalogues of buttons. Name an unfamiliar surface in context on first use, for example **Editor’s file sidebar (Explorer)**. Put each illustration beside the task it teaches. Home is the elevator pitch for Open Clank as a whole. Open with what a person and their Clanker can do together. State the product’s capabilities directly. Put worked examples on the feature pages. Keep Home’s third footer link pointed at Manual Index. Group every guide there by reader task.

**Copal** is the sidebar section containing Journal and the learning tools. A **journal** is the reader’s named workspace. A **journal page** belongs to that workspace. Use the journal's actual name when describing a selected workspace. Editor, Wiki mode and Graph mode keep their own names. Refer to an official manual article as a **manual page**. Use the technical name Copal when identifying the software or interchange format.

Write maintained English bodies in `src/openclank/official_docs_content.py`. Keep document IDs, aliases and working section embeds. Put each workflow on one page. Link related tasks from Home and update Buddy’s topic mapping in `official_docs.py` when a help target moves. Publish the combined edition with one increment to its seed version.

Use screenshots or diagrams where they show how to recognize a control, state or relationship. Record the source, alt text and a short caption in `official_docs_assets.py`. Add the asset ID to the article's `ARTICLE_ASSETS` entry. Insert `{{manual-media:asset-id}}` on its own line with blank lines around it next to the relevant instructions. The installed handbook and localization export expand the marker into the image and caption. Preserve text instructions for readers who cannot see the image. In translations, retain section order and heading levels so section links still land. Localize visible link labels, image alt text and captions. Keep wiki targets, app routes and media URLs intact. Use the current English instructions when a translation is pending.

For promo images and manual illustrations, use the Comic Clank kit. Set prose and headings in Comic Clank and code or monospaced UI in Comic Clank Mono. For a screenshot, load the faces in the capture window before taking it and check the rendered font on representative text. Keep a diagram’s lettering portable by embedding or outlining its glyphs. Record which faces produced the published image.

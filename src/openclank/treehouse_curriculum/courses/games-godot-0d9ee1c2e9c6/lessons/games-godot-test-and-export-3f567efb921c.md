# Test outside the editor

- Install matching 4.7.2 templates through Editor→Manage Export Templates. In Project→Export, add a preset for your supported desktop platform and export to a disposable folder outside the editable source. A PCK/ZIP resource pack alone is not a playable build.
- Close the editor and launch that exported executable. Check input, win, timeout and restart after each outcome. Press R twice: score returns to zero, position to (80,180), and timer to 20 seconds without duplicate handling.
- Record exact version, renderer, OS, reproduction steps and any error. A successful editor run does not prove export works; unavailable templates or a build that cannot run leave this practical task pending.
- Keep the editable project. A binary alone cannot explain your rule change.

**Self-check:** Export and run the game. Report platform, exact versions, reproduction steps and one check that would catch a missing resource or wrong main scene.

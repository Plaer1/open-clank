# Check a link and its destination

- A wiki link is useful only if it resolves to the intended resource. Follow it and inspect the destination identity; titles alone can collide.
- Official Help is read-only. An eligible personal copy of nonofficial material gets a new personal identity; it does not make the official source editable.

**Offline inputs:** Review contains `# Review\nSee [[Details]].`; Details contains `# Details\nColor: blue\n[[Review]]`. Supplied resolution receipt: Review's link opens Details; Details' link opens Review. Use the app's actual generated link syntax when practicing, because import/export formats may differ.

A rendered .memes resource and a Markdown export need not have identical bytes.

To record your own commentary on official Help, create a separate authorized personal note and link to the source. The missing official edit action is a permission boundary, not a missing shortcut.

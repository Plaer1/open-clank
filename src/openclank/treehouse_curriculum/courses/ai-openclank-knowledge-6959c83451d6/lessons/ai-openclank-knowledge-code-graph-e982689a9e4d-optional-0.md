For a useful bug report, retain workspace scope, current source revision, index status/revision, relationship type and target location. Do not include private code merely to prove that a stale pointer exists.

In Code Graph (Alpha), **Refresh now** verifies saved source through the existing index owner. Automatic source verification can do this while a ready graph is visible; external changes may wait for its configured interval. After terminal failure, choose **Retry indexing** unless a newer validated in-scope saved-file or root-watch signal permits one recovery attempt. Focus, visibility and periodic timers do not repeatedly restart failed work. Without such a scoped signal, including for nested external edits after failure, retry explicitly. An offered **Retry indexing** handles recovery, while an erased scope requires explicit readmission. **Stop observing** detaches this view without cancelling other consumers. Layout changes do not make stale evidence current, and a retained old graph during refresh must be read with its last verification time. Record unknowns explicitly: missing coverage is not proof of no edge.


**Settings → System → Code indexing** controls indexing threads, selected-file capacity, total source bytes, per-file bytes and the derived-generation disk budget (2 GiB default, configurable up to 8 GiB). Saved/requested and effective values can differ while active indexing drains. The disk budget bounds derived index storage; it does not reserve free disk space or increase source/display limits.

# Read capability availability at the destination

- Native capability discovery reports what this host/session can expose. A terminal capability is not automatically a browser control.

**Offline cards:** A implemented and available, destination current native session. B host-equivalent but unavailable, reason no negotiated route. C terminal-only, no browser destination. D document editor exists, selected resource writable=false.

Choose a supported destination or record the missing prerequisite. Neither a registry name nor an enabled-looking label proves an action can run in this surface.

Current MiMo entitlement, limits and billing must be checked in the applicable account/provider controls. This packet has no readable current MiMo pricing/entitlement receipt and supplies no invented rates.

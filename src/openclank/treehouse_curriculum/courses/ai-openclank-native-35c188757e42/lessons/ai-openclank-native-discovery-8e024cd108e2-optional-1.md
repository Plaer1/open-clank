MiMo Code exposes a native tool registry, while Open Clank decides which operations the current route admits. Native read/write/edit/search names do not imply direct filesystem ownership: scoped host adapters can provide those operations while native file/process aliases remain disabled. The current bridge excludes direct bash, python, get_workspace, apply_patch, web_search, web_fetch, ask_user and update_plan routing. Public host tools have their own policy. Actor, memory/history, tasks and tool-script capabilities—and gated LSP, cron, session and workflow features—must be checked against current negotiation, model and flags. A missing capability should remain unavailable rather than be simulated as a successful tool call.

# Language generation and its limits

- LLM means large language model: a language-oriented trained model, not a product or a complete agent.
- An autoregressive language model repeatedly predicts a next token from context. The generated token becomes part of the following step's input.
- Pretraining learns patterns; instruction-oriented post-training can change how the model responds to requests.
- Fluent continuation can contain invented details. A plausible citation still needs to resolve to a source supporting the claim.

A system answering a question may generate text, retrieve documents and call tools. Its accuracy depends on the whole process.

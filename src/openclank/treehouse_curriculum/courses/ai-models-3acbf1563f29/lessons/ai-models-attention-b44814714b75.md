# Attention relates the available pieces

- Attention forms a representation using weighted contributions from other available positions. The useful relationships are learned.
- Transformer architectures use attention to connect sequence elements without requiring every relationship to travel through successive recurrent steps.
- An attention pattern is part of computation; it is not a complete explanation of why an answer is correct.

In “The box beside the cups is blue,” relating “is” to “box” can be useful despite intervening words. This illustrates a relationship, not an inspection of a particular model.

# Model, architecture and checkpoint

- AI is the broad category of machine systems used for prediction, perception, planning and related tasks. Machine learning learns behavior from data; deep learning uses multiple learned neural layers. A learned decision tree is ML without being a deep neural network. Not all AI is neural, and not all ML is deep.
- A model maps inputs to outputs using learned parameters. An architecture describes how its computation is arranged; a checkpoint stores a particular trained parameter state.
- Two checkpoints can share an architecture and behave differently because their training differs. An application also adds instructions, tools and interface behavior.

Example: a Transformer blueprint, a trained translation checkpoint and a translation website describe three different things.

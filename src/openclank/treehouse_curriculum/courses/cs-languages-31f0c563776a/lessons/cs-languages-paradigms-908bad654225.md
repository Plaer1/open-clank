# Different ways to express work

- Imperative code describes state changes. Functional style composes value-producing functions and can avoid shared mutation.
- Objects combine state and behavior behind interfaces. Declarative code states a desired relation or result, leaving execution strategy to an engine.
- Languages often support several styles; a paradigm is not a speed guarantee.

# A first Python program

- A function binds arguments to parameters; `return` sends a value to its caller. `print` writes output.
- Save-as name: `first_sum.py`. Reading and tracing this complete program needs no interpreter.

```python
def add(a, b):
    return a + b

print(add(2, 3))
```

**Try:** Predict the helper's result and printed line. Change only the second argument to `0` and predict again. Restore the arguments, then predict changing `+` to `-`. Explain which line computes and which writes output.

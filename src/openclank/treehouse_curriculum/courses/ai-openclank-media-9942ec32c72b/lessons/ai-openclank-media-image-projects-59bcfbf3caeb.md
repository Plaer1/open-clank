# Preserve an editable image project

- Image-project save preserves editable project structure; flattening an image produces pixels without that layer structure.
- Record source material, edits and rights alongside an exported asset. Generated or edited output still needs inspection for its intended use.

**Offline project p1 revision 1:** canvas 16 × 16. Layer blue-base is fully opaque blue. Layer yellow-mark is transparent except a 4 × 4 yellow square at the origin. Requested edit: paint overlay pixel (0,0) red. Supplied saved p1 revision 2 has both layers and the red pixel. Flattened PNG is 16 × 16 and has no editable layers.

Provenance card: both original practice layers are first-party, MIT; edit is the one red pixel. The supplied card is a specification, not a generated file or actual editing receipt.

Before sharing, inspect the intended export, provenance, permissions and recipient access. If an optional AI edit returns unavailable/error, keep the original project and report the failed attempt; do not claim the pixels changed.

# Rules that can be played

- A rule tells you which actions are legal and how they change the game. A theme tells you what those actions mean in the fiction.
- Tiny game: start with 7 counters; players alternate removing 1 or 2 counters that are present; whoever removes the last wins. State is counters remaining plus whose turn it is.
- The repeated loop is observe → choose → act → see the result. A match and a campaign can wrap larger loops around it.

**Self-check:** Write the state after removing 2 from 7. Give a legal next action, an illegal action and an exact win test. Change one rule and predict how decisions change.

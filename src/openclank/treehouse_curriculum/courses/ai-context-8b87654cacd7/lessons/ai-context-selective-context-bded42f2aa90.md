# Retrieve detail when it becomes relevant

- Keep a compact index and retrieve relevant passages on demand. Save source identity and location with the extracted conclusion.
- Clearing stale tool output can reduce clutter after useful evidence is preserved. Do not clear the only recoverable copy of a needed result.
- Context compaction differs from lossless file compression and from model compression such as quantization or distillation.

A 400-page manual has two relevant sections. Load those sections and record their version; the whole manual need not remain in every request.

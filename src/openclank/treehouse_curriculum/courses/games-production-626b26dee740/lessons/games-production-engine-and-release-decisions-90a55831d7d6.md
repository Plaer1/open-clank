# Choose constraints before a stack

- State the target: 2D or 3D, editing workflow, team languages, deployment platforms, content pipeline and performance budget. An engine bundles different amounts of runtime and authoring work.
- Godot and Bevy are concrete branches here. Unity, Unreal, Defold, GameMaker, Cocos Creator, O3DE and CryEngine are comparison candidates, not an implied ranking or current price table. Check official support and terms for the exact release before adopting one.
- Premium sales, expansions, cosmetics, consumables, subscriptions, season passes and ads create different player promises and incentives. Make prices/entitlements understandable; test whether the reward system pressures unwanted behavior.
- A release record includes tested builds, known limits, rights/provenance, install/save/recovery instructions and an update plan. Platform certification and commercial terms require their actual current sources.

**Self-check:** Write a one-page decision for a small offline 2D game: three constraints, two candidates, one prototype test, one unresolved adoption question and a clear player-facing release claim.

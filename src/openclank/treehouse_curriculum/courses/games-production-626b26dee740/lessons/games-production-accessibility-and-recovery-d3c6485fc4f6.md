# Make play and recovery reachable

- Test remappable controls, visible focus, keyboard navigation and clear error recovery. Allow alternate inputs when a mechanic permits them.
- Present essential cues in more than one way: shape/text plus color, visible feedback plus audio; captions should identify meaningful sound where needed.
- Check readable text, contrast, motion reduction, time limits, pause and assist options. A web checklist helps the interface but is not a complete assessment of a game.
- Include failure states: disconnected controller, lost network, missing asset and loading an older save. Tell the player what happened and what they can do.

**Self-check:** Review a timed collectible game with red/green targets and sound-only success. Propose three specific changes and a keyboard-only test.

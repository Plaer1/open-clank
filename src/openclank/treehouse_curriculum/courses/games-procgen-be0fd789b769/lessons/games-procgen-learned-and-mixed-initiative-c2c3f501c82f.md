# Generated appearance needs game tests

- Learned generators infer patterns from examples; rule-based generators encode explicit procedures. Hybrid tools can propose with a model and validate with rules.
- N-gram/Markov methods model local transitions; VAE, GAN, diffusion and transformer families offer different generation mechanisms. Their canonical explanations live in AI.
- A generator can suggest a room, item description, quest or motion. Test affordances: can the player climb it, equip it, finish it or interrupt it?
- In mixed-initiative work, the creator supplies constraints, inspects proposals and revises. Record accepted and rejected outputs, not only attractive examples.
- Check distribution across player abilities and content categories; a model's repeated pattern can create inaccessible or unfair outcomes.

**Self-check:** An image model draws a staircase with inconsistent step heights. Propose one geometric validity check, one player-controller test and one human review decision. No paid generation is required.

# Propagation is not a path guarantee

Optional practice.

- Three cells 0–2, tiles A/B; neighbors must differ. Domains {A},{A,B},{A}. Compare last domain {B} instead.
- Grid rows S.. / ### / ..E permit four-neighbor moves. Open middle-row rightmost cell.
- Separate 5×5 layout: wall column x=2; S=(0,2), E=(4,2). Open doorway (2,2).

**Self-check:** Propagate both domain cases. Trace the opened path in each grid and distinguish adjacency validity from reachability.

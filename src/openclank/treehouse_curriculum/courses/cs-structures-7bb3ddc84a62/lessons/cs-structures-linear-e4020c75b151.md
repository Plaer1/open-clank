# Arrays, lists, stacks, queues

- An array supports indexed access; insertion may shift many elements. A linked structure follows links; finding an arbitrary position takes traversal.
- A stack removes the newest item (LIFO). A queue removes the oldest (FIFO).
- Enqueue A,B,C then dequeue returns A; pushing A,B,C then popping returns C.

**Try:** Trace both examples and choose a queue representation that avoids shifting all remaining items on every removal.

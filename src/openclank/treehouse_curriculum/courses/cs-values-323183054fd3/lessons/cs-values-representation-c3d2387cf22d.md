# Bits and numeric limits

- Bits store a pattern; a representation gives it meaning. Eight bits have 256 distinct patterns.
- `11111111` means 255 as an unsigned byte and −1 in eight-bit two's complement.
- Fixed-width integers have bounds. Binary floating point approximates many decimal fractions; compare with a tolerance suited to the task.

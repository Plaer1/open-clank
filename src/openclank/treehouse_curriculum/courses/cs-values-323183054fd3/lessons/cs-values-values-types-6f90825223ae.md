# Values, types, expressions

- A value is data; a type determines which operations have meaning.
- An expression computes a value. In Python, `2 + 3` is integer `5`; `"2" + "3"` joins text into `"23"`.
- Converting text to a number is an explicit decision; invalid text needs an error path.

**Try:** Give the results and types of `4 + 2`, `"4" + "2"`, and `int("4") + 2`. Explain why `int("pear")` needs handling.

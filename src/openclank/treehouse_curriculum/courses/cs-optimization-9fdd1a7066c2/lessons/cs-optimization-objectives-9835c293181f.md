# Feasible choices and objectives

- A decision variable names a choice; constraints define the feasible set; an objective ranks allowed choices.
- Options A:(cost 2,latency 8), B:(cost 4,latency 3), C:(cost 7,latency 1). Under cost≤4, minimizing latency chooses B.
- The optimum is relative to the model. Omitted requirements can invalidate the recommendation.

# Pareto and uncertainty

- A feasible option dominates another if it is no worse in every chosen objective and strictly better in at least one.
- For minimizing (cost,latency), A=(2,8), B=(4,3), C=(5,9): compare each pair using both coordinates.
- Expected-cost optimization uses probabilities; robust choice protects against a stated uncertainty set. Neither defines fairness automatically.

**Try:** Find the nondominated options. State a preference or constraint that selects between them and one uncertainty that could change the decision.

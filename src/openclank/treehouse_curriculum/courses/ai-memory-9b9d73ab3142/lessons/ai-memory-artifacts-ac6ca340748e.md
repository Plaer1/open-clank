# Leave a usable record

- A durable artifact preserves decisions and evidence beyond one context window. It needs a location, purpose, current status and a way to find supporting material.
- Keep sensitive material under its original access controls. A public summary must not expose private logs or credentials.
- Preserve recoverable preimages before replacing work; a new summary is not a backup of exact old content.

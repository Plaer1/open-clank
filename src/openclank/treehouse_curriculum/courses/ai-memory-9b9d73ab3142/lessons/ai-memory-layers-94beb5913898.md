# Ask which memory is involved

- Parameters retain what training changed. Current context contains what inference can use now.
- Conversation history stores prior turns. Persistent app memory stores selected information across conversations.
- Retrieval brings external records into context. Artifacts—notes, files and handoffs—preserve work for later reading.
- Storage does not guarantee automatic injection, freshness or permission to read.

A saved preference can exist in a database without being present in the current model request.

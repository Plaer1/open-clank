# Build meaningful HTML

- HTML gives a page structure: `title` names its browser tab, while `h1` is a visible main heading. Headings describe the content hierarchy.
- `main` holds primary content; `nav` contains navigation. An anchor with `href` navigates; a button performs an action.
- `<label for="name">Name</label><input id="name" name="name">` explicitly associates a name with a control.
- “Complete local starter” below supplies sibling `index.html` and `style.css`: save both in a fresh folder. `link href="style.css"` attaches the stylesheet.

**Try:** Using that starter, write a meaningful fragment with a main heading, navigation link and labeled name input; explain the chosen elements. Change the h1 text, retain h1→h2→h3 hierarchy, and identify what changes in the tab title versus page heading and what preserves the label association.

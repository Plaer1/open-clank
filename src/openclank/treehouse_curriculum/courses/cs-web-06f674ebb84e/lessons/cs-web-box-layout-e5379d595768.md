# Boxes, flex and grid

- The box model separates content, padding, border and margin. `border-box` includes padding/border inside specified width; margins remain outside.
- Separate arithmetic example: content-box width100px, padding10px on each side, border2px on each side. This is not a measured card from the starter.
- Flex arranges a main axis; grid defines rows and columns. The starter uses flex for wrapping navigation and grid for cards.

**Try:** Calculate the separate example's outer width before margins. Optionally compare specifying100px with border-box. Choose flex or grid for a row of controls and a two-dimensional card arrangement, explaining why neither choice is mandatory.

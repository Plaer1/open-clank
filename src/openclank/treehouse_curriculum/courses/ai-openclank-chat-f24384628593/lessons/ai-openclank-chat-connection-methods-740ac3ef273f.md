# Choose the offered connection method

- Open Clank login, provider authorization and mail login are separate relationships.
- Use the methods offered for the selected provider. A generic subscription does not imply API access; an explicitly supported subscription login is product-specific. Check the account's current entitlement and billing controls.

**Offline connection card:** owner learner-a. Cedar: disconnected, method index 0 `API key`. Juniper: disconnected, method index 1 `Device login`. Fir: no methods offered. Local-mini: `http://127.0.0.1:8100/v1`, catalog returned `tiny-practice`, chat not attempted. Shared-mini: teacher-b owns the source credential, learner-a has not subscribed.

Select the listed method by its label and capability. Catalog discovery is not a successful chat, provider entitlement, or a promise of free use.

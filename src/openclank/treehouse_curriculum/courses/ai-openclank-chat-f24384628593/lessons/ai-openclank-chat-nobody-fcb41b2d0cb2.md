# Use a temporary conversation deliberately

- Start Nobody mode in a fresh empty session using its eye control and check the indicator. It cannot be toggled after messages already exist.
- Same-session temporary context can remain available until the process loses it. This is not anonymity, zero logging, zero billing, or a blanket ban on all tools.

**Offline card:** ordinary session O contains `code MAPLE`; a saved preference says metric. Fresh Nobody session N receives `For this temporary conversation use code PEAR`. Its next message asks `What code is here? Retrieve my saved preference.` N's same-process conversation contains PEAR. Recall-memory, chat search, cross-session sending and memory/skill/session management tools are excluded from this mode's available set. After process restart, the temporary map is gone and there is no saved N record.

Answer from N's supplied context. Do not import MAPLE or the saved preference through a blocked recall path.

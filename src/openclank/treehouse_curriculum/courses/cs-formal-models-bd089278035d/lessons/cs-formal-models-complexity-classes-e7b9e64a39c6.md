# Decidable versus tractable

- P contains decision problems solvable in polynomial time under the standard model. NP contains those with polynomial-size yes-witnesses verifiable in polynomial time.
- A proposed satisfying assignment can be checked by evaluating every clause; finding one may be harder.
- NP does not mean non-polynomial. P versus NP remains an open problem.

**Try:** For a Boolean formula, describe a yes-witness and verification. Explain what a polynomial reduction A→B would let a fast solver for B do.

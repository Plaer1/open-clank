# Choose a logic for the question

- Temporal logic talks about behavior over time: 'always safe' differs from 'eventually finished'. Epistemic logic models what an agent can distinguish or know.
- In a possible-worlds knowledge model, an agent knows P only when P holds in every world it considers possible. Such idealized models can assume unrealistic reasoning power.
- Changing inference rules or truth values changes the logic; specify those rules before drawing conclusions.

**Try:** A job remains pending forever without crashing. Does it satisfy 'always no crash' and 'eventually finished'? Explain what a time-bounded observation cannot establish.

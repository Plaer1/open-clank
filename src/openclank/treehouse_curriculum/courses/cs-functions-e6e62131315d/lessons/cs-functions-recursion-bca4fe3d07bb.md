# Recursive calls

- Recursion solves a problem using smaller instances. A base case returns without another recursive call.
- For n≥0: `sum_to(0)=0`; `sum_to(n)=n+sum_to(n−1)`.
- The decreasing n explains termination over this domain. Negative n would never reach zero under this rule.

# Keep focus and permission visible

- Split views help compare resources, but keyboard actions affect the focused surface. Check focus before typing or using a shortcut.
- A disabled edit action on official Help reflects that resource's permissions. Do not describe a shortcut as an override.

**Offline layout:** left pane Review.md; right pane Details.md; focus is in Details. A third pane is read-only official Help. Typing `Color: green` affects the focused Details draft. Save is disabled on Help.

Switch focus explicitly to edit Review. Use the controls available on the selected resource rather than assuming every host provides identical shortcuts.

**Draft check:** Review also contains an unsaved note `Keep this draft`. Preserve it before closing/reloading that pane; changing focus need not discard it.

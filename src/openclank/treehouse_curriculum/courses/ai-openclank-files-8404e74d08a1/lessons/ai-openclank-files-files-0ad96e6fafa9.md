# Choose the right resource and operation

- Use Files to identify the resource, location and write permission before creating, moving or restoring work. A download or publication is a different operation.
- An unsupported file handler can offer download or open elsewhere; it does not make the content editable here.

**Offline listing:** authorized private location P is writable; R is read-only. Page 1 of P lists Review.md; page 2 lists Details.md. Review contains `# Review\nStatus: draft\n\nSee the details note.` Details contains `# Details\nColor: blue\nNext check: reopen the saved note.` A create attempt in R is denied. A trashed Review retains its resource identity in the supplied restore receipt.

Navigate the next page to find Details. Choose P for a new disposable note. Restore from the recorded trash state; do not represent a download as restoration.

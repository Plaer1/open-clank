# Predicates and quantifiers

- `and`, `or`, and `not` combine claims. An implication P→Q fails only when P is true and Q is false.
- ∀ means every; ∃ means at least one. Negating 'every item is valid' gives 'some item is invalid'.
- State the domain: a claim about list indices applies only to 0≤i<n.

**Try:** Negate 'for every submitted file, the size is at most 10 MB'. Give a counterexample and explain the empty set case.

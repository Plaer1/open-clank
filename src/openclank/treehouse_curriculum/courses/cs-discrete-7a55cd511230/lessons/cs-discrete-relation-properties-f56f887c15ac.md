# Test a relation's rules

- Reflexive: every `(x,x)` exists. Symmetric: `(x,y)` implies `(y,x)`. Antisymmetric: both directions imply x=y.
- Transitive: `(x,y)` and `(y,z)` imply `(x,z)`. Antisymmetric does not mean “never symmetric.”
- On `{0,1,2}`, let `R={(0,0),(1,1),(2,2),(0,1)}`. A partial order is reflexive/antisymmetric/transitive; an equivalence is reflexive/symmetric/transitive.

**Try:** Check all four properties with witnesses or counterexamples. Add `(1,0)` and reassess. If it becomes an equivalence, list its classes.

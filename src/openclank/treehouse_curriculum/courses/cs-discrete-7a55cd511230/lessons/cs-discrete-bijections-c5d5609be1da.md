# One-to-one and onto

- A function gives one output to each domain member. An injection never merges distinct inputs; a surjection reaches every codomain member.
- A bijection satisfies both. Changing the codomain can change surjectivity without changing any mapped pair.
- Let `A={0,1,2}`, `B={a,b,c}`, and `f={(0,a),(1,b),(2,c)}`.

**Try:** Decide injection and surjection, giving evidence. Separately (1) replace f(2) with b, keeping B, and (2) restore f and enlarge B with d. Explain what fails in each version.

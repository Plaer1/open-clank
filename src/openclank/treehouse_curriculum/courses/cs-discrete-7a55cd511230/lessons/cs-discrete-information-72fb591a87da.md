# Information and compression

- A fair binary outcome needs one bit to distinguish its two equally likely cases; a certain outcome adds no uncertainty.
- Shannon entropy averages surprise: H=−Σp log₂p. It describes a distribution, not truth or importance.
- Compression exploits structure. A lossless code must let the decoder reconstruct each allowed message uniquely.

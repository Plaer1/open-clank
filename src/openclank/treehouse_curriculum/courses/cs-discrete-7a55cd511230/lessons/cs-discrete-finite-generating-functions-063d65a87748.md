# Count with polynomial coefficients

- A slot allowing counts0 or1 contributes `1+z`; the exponent records the count chosen.
- Multiply one factor per distinguished slot. Products combine choices; adding coefficients counts ways with the same total.
- Three slots each allow0 or1, so use `(1+z)^3`. This is a finite polynomial: no convergence question is needed.

**Try:** Expand it and explain the coefficient of z² by listing triples. Change only the last slot's options to {0,2}; write and expand the new product, then list its total-two triples.

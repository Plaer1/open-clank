# Repeated random transitions

- A Markov model summarizes the next-state distribution using the current state. It is useful only when that state retains the relevant information.
- If dry→wet has probability 1/4 and wet→wet has probability 1/2, starting dry gives wet probability 1/4 after one step.
- Average behavior is not a guarantee about a particular run.

**Try:** Compute wet probability after two steps. Name a missing variable that could invalidate the current-state assumption.

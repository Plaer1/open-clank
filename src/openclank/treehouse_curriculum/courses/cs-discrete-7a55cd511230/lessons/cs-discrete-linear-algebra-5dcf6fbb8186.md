# Vectors and linear transforms

- A vector is an ordered list of components relative to a chosen basis. Addition and scaling act componentwise.
- A matrix defines a linear map: [[2,0],[0,3]] sends (1,2) to (2,6).
- Order matters when composing transforms. A translation alone is affine, not a linear map of the original vector coordinates.

**Try:** Apply [[0,−1],[1,0]] to (2,1), then scale x by 2. Compare with scaling x first.

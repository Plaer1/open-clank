# Sets, mappings, relations

- A set records membership; order and repetition do not matter. Union combines members; intersection keeps common members.
- A relation is a set of ordered pairs. A function gives exactly one output for each element of its domain.
- A dependency relation need not be symmetric: A needing B does not make B need A.

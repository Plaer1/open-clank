# Explain the exact path before changing it

- Workspace Hexes govern matching paths. Inspect the exact target's rules before writing; preserve the actual current preimage before replacement.
- Authorization to edit content does not automatically authorize changing its governing rules or trusting executable checks.

**Offline card:** target practice/Review.md. Its rule requires a recoverable preimage. Git's committed version is blue, but the current uncommitted file is red. The proposed change is green. Preserve red in an accepted recovery authority, then perform only the authorized content change. Saving only committed blue would lose the actual preimage.

General Hexes are separate reusable owner defaults; their applicability is covered in the adjacent exercise.

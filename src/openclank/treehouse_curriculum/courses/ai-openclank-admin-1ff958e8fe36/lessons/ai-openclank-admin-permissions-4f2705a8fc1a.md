# Check resource permission and OS confinement

- App-level grants govern the app operation. The host operating system is the process-confinement boundary; an app permission does not replace it.

**Offline card:** user A has write permission in workspace P and read-only permission in R. Requested destination is R/result.md. The app denies the write. P/result.md is an authorized alternative if appropriate to the task. A plugin's presence does not change either resource grant.

Preserve the output as a draft or choose a permitted destination. Do not weaken a rule merely to make a task pass.

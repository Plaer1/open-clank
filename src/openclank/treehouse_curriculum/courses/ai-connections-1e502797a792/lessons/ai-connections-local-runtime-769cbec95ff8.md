# Downloaded weights are not a running endpoint

- Weights, a compatible runtime, a running server and a loaded/healthy model are separate states.
- Check model format/license, hardware resources, endpoint compatibility and observed readiness. No provider fee does not imply zero machine or electricity cost.
- Download, serve, status and cancel operations vary by runtime; inspect its supported controls before optional use.

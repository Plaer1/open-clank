# When future rewards change today's choice

Optional practice.

- Stage payoffs: C,C→3,3; unilateral D→5,0; D,D→1,1. Indefinite repetition, perfect observation, discount δ.
- Stated grim-trigger policy: cooperate until a deviation, then D forever. Cooperation value 3/(1−δ); one-shot deviation value 5+δ/(1−δ).

**Self-check:** Compare δ=1/4,1/2,3/4. Explain what noisy monitoring or a known final round changes.

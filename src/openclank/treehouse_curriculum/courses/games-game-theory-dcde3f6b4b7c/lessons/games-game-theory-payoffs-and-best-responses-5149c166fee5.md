# Read a payoff table

- Game design asks what experience rules produce. Game theory studies choices whose consequences depend on others' choices.
- Payoffs represent preferences in this model, not an objective measure of fun. Each pair below is (row player, column player).

| | Cooperate | Defect |
|---|---|---|
| Cooperate | 3,3 | 0,5 |
| Defect | 5,0 | 1,1 |

- Fix the other player's choice before comparing your options. A best response is best against that choice; a strictly dominant strategy is better against every opposing choice.
- A Nash equilibrium allows no profitable unilateral deviation. It need not maximize the total payoff.

**Self-check:** Mark both players' best responses and the equilibrium. Compare its payoff sum with mutual cooperation.

# Plans include later choices

- A strategy specifies what to do at every decision you could face. In a tree, start at the last decision to test whether a threat would actually be carried out.
- Example: after entry, the incumbent receives 2 by sharing or 0 by fighting. A threat to fight is not credible under those payoffs.
- Repetition makes history relevant: future cooperation can affect today's incentives. It does not guarantee cooperation.
- A stochastic game adds a changing state; a repeated game repeats the stage interaction. State can change which actions and payoffs are available.

**Self-check:** An entrant earns 1 from entry if sharing follows and 0 from staying out. Predict the choices by working backward. Give one change that could make fighting credible.

# Divide a joint gain

- A coalition model assigns a value to each group. The core asks whether some group could leave and give all its members a better deal.
- Shapley allocation averages each member's marginal contribution over joining orders. It is one allocation rule, not a universal definition of fairness.
- Example: A alone produces 2, B alone 0, together 6. A contributes 2 then B 4 in order A,B; B contributes 0 then A 6 in order B,A.
- Bargaining also needs a disagreement outcome. Negotiating over 6 with fallback (2,0) is different from fallback (0,0).

**Self-check:** Average the two joining orders. Check whether either player prefers their solo value to that allocation.

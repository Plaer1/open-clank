# Reason with what players know

- Hidden actions and hidden types are different. An information set groups decision points a player cannot distinguish; a type can encode private strength or preferences.
- Beliefs matter: a signal is useful only through how it changes a receiver's expectations and choices. A bluff can be attractive when the sender benefits from being misread.
- Correlated recommendations need not be independent coin flips. Their equilibrium test is whether each player wants to obey given their own recommendation.
- A proposed belief is a model assumption, not observed truth.

**Self-check:** Two players choose left or right; each receives 1 for matching and 0 otherwise. A mediator recommends the same randomly chosen side to both. Explain why following is a best response after either recommendation; compare independent fair coins.

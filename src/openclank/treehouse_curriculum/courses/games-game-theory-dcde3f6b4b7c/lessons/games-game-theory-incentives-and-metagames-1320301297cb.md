# Test the reward rule

- Mechanism design starts from a desired result and chooses rules that make it attractive to participants.
- Paying for every hit can reward harmless hit farming; paying for a completed objective can shift behavior. Write the exploit before tuning the reward.
- Evolutionary reasoning asks how successful strategies spread in a population. A popular strategy is not necessarily an evolutionarily stable strategy; ask whether a rare alternative can invade.
- Shared-resource games create external costs. If two players each prefer the short route but together overcrowd it, individual best responses may waste time. Price of anarchy compares worst equilibrium cost with optimal total cost in a specified model.

**Self-check:** Design a team-objective reward, show one farming strategy, and revise the rule. For routes costing n minutes on route A when n users choose it and 1.5 minutes on route B, compare total costs with two players both on A versus split.

# Separate current requirements from history

- Current completion follows the current required assignment set. Historical receipts remain history when requirements change or progress resets.
- Elective work contributes to its own scope; it does not silently add a core requirement. Artwork is a display, not a separate completion authority.

**Offline card:** required course C has two responses; one is submitted under generation 3. Historical generation 2 had a complete receipt. Another equally weighted required course is complete. The root's current mean is (1/2 + 1)/2 = 75%. Reset C creates generation 4 pending; the generation-2 receipt still exists historically.

Four Main Quests have independent scopes. Do not average unrelated roots or treat a historical trophy as a current requirement receipt.

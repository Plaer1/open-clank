# Preview an owned lesson and its assignment

- In an owned private course, add a lesson and an assignment, then inspect Learner preview. Save the authored draft before checking what learners see.
- Preview is not publication or a learner submission. Authoring does not require an AI call.

**Complete offline lesson source:**
```markdown
# Save a note
- Open the supplied note.
- Change blue to green, save and reopen.
```
Title: Save a note. Outcome: distinguish a draft from a persisted change. Assignment: `Explain the before, draft and reopened states.` Cards: disk revision 1 blue; draft green; saved/readback revision 2 green. Draft author receipt: private P, owned by A, saved revision 1. Learner preview shows the title, steps, cards and assignment; no publication receipt exists.

A useful preview catches a missing input card or hidden assignment before sharing.

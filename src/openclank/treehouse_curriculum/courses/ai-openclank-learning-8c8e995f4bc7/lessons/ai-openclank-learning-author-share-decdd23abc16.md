# Know which course you can edit

- Personal authorship, system-course reading and sharing grants are separate permissions. A visible lesson is not necessarily editable.

**Offline roles:** A owns private course P. B can read system course S and submit B's own responses, but cannot edit S. E has an explicit edit grant on P; E is not P's owner and has no additional sharing grant. Publication and sharing are separate from an author's preview.

Use the owner or explicitly granted operation. Do not use a personal copy to claim that the official system source changed.

**Linked-resource card:** P's package references image R in A's private Files. B can read the shared course but has no grant to R; the image is unavailable. Report the missing authorized resource or arrange an explicit appropriate grant; sharing definitions alone does not grant R access.
